## Brand & Style

The design system embodies computational optics, browser-native convolution processing, and precision algorithmic manipulation. It merges high-performance graphics engineering with the tactile fidelity of an advanced creative studio. 

The aesthetic is futuristic, scientific, and darkroom-inspired:
- Deep obsidian canvas tones allow vibrant mathematical matrices, spectral beams, and high-frequency pixel structures to emerge with crisp luminosity.
- Glassmorphic HUD elements evoke laser-etched optic planes and floating matrix overlays.
- Sharp computational grid accents, coordinate indices, and monospaced parameters coexist alongside sweeping optical gradients and electric neon emissions.
- Interfaces inspire focus, scientific curiosity, and technical empowerment, balancing raw algorithmic power with effortless studio polish.

## Colors

The palette is tuned for high-contrast dark room manipulation, utilizing deep violet-tinted blacks and intense spectral hues:

- **Primary (`#A855F7` - Electric Violet):** The focal signature. Used for primary interactive triggers, active processing stages, focused matrix nodes, and radiant ambient halos.
- **Secondary (`#EC38BC` - Vibrant Magenta):** High-energy companion accent. Combined with electric violet in gradient blends for primary calls to action, transformation vectors, and kernel sweep lines.
- **Tertiary (`#5EEAD4` - Accent Cyan):** The technical readout marker. Reserved for computational coordinate matrices, kernel weight values, status pings, and edge detection visualizations.
- **Neutral Base (`#08070D` - Obsidian Abyss):** The canvas floor. Provides complete darkness with subtle purple undertones to maximize color radiance and prevent eye fatigue.
- **Elevated Surfaces (`#14101F` - Deep Chamber):** Floating panes, matrix inspector drawers, and floating tool docks.
- **Text & Contrast Tiers:**
  - Header & Primary Readouts: Crisp White-Lavender (`#F7F5FF`)
  - Subheaders & Secondary Data: Muted Slate Violet (`#A8A1BA`)
  - Structural Borders & Grids: Translucent Electric Violet (`rgba(168, 85, 247, 0.15)`)

## Typography

The typographic hierarchy establishes a deliberate contrast between mechanical precision and forward-looking display scale:

- **Display & Headlines (Space Grotesk):** Features bold, geometric letterforms with tight tracking. Headlines convey scientific confidence and algorithmic impact.
- **Body & Continuous Text (Plus Jakarta Sans):** Balances geometric structure with comfortable legibility on screens. Ensures effortless readability across dark backgrounds without visual vibration.
- **Mathematical Readouts & Labels (JetBrains Mono):** Reserved for matrix values `[-1, -1, 8]`, coordinate trackers, shader names, execution timing (`ms`), and micro-indicators. Rendered strictly with uppercase tracking or clean tabular numerical alignment.

## Layout & Spacing

The layout operates on a fluid 12-column grid system paired with strict 8px/4px computational increments:

- **Canvas Architecture:** Desktop displays maximize working room with standard `3rem` (48px) margins, adapting to `1.25rem` (20px) on mobile breakpoints.
- **Inspector Panels & Split Workspaces:** Image viewports and matrix workspaces lock to fluid column proportions, maintaining a fixed 48px or 64px tool dock flanking the active inspection canvas.
- **Matrix Array Rhythms:** 3x3, 5x5, and 7x7 convolution cells utilize tight `space-xs` (4px) to `space-sm` (8px) internal gaps to mirror actual tensor data structures.
- **Breakpoints:**
  - `Mobile` (< 768px): Single column stacked layout. Matrix inspectors collapse into drawer sheets; control knobs pivot to horizontal scroll trays.
  - `Tablet` (768px - 1199px): 8-column layout. Side-by-side comparison viewports convert to slider tabs.
  - `Desktop` (≥ 1200px): Full 12-column configuration with simultaneous canvas, live shader timeline, and matrix inspector visibility.

## Elevation & Depth

Visual hierarchy is constructed through luminous optical layering, tinted translucency, and spatial glowing conduits rather than traditional flat drop shadows:

- **Base Layer (Elevation 0):** Background canvas (`#08070D`), decorated with subtle computational background grids (`rgba(168, 85, 247, 0.04)` line weight).
- **Surface Layer (Elevation 1):** Card containers and docking bars (`#14101F` at 85% opacity with `backdrop-filter: blur(16px)`). Edges are defined by a crisp 1px ghost border `rgba(168, 85, 247, 0.2)`.
- **Active Node / Hover Layer (Elevation 2):** Elevated floating inspector panels or active matrix cells (`#1E1730`). Enhanced with an ambient electric violet glow: `box-shadow: 0 0 32px -8px rgba(168, 85, 247, 0.35)`.
- **Ethereal / Laser Split (Elevation 3):** Scanning lines, primary CTAs, and active kernel sweep vectors. Utilizes a vibrant linear gradient (`#EC38BC` to `#A855F7`) complemented by an intense dual-stage bloom: `0 0 20px rgba(236, 56, 188, 0.5), 0 0 40px rgba(168, 85, 247, 0.3)`.

## Shapes

The interface balances sleek capsule elements with rounded geometric containers:

- **Pill Geometry (`rounded-full` / Level 3):** Applied to primary action buttons, tool mode pills, status chips, floating navigation headers, and matrix parameter tags to evoke laser lenses and smooth tactile toggles.
- **Container Geometry (`rounded-2xl` to `rounded-3xl`):** Canvas viewports, image comparison frames, and inspector cards utilize generous outer curvatures (16px to 24px) to soften technical complexity.
- **Micro-Matrix Nodes (`rounded-md`):** Individual numeric weight cells within the 3x3 convolution grid retain slight structural curvature (6px) to maintain rigid data-grid coherence.

## Components

### Buttons & Interactive Controls
- **Primary CTA:** Fully rounded pill silhouette filled with an angled gradient from `#EC38BC` to `#A855F7`. Features crisp `#FFFFFF` typography and an ambient dynamic glow. On hover, the intensity of the violet shadow expands by 30%.
- **Secondary / Ghost Button:** Transparent pill backdrop bordered by 1px `rgba(168, 85, 247, 0.3)`. Background fills with `rgba(168, 85, 247, 0.1)` on hover with `#F7F5FF` text.
- **Icon Buttons:** Circular HUD triggers (`40px × 40px`) housed in elevated `#14101F` glass surfaces with subtle border strokes.

### Convolution Matrix Grid
- **Matrix Cells:** 3x3 / 5x5 computational squares arranged with 4px gaps.
- **Numeric Values:** JetBrains Mono bold text. Default weights render in `#A8A1BA`; modified or non-zero weights highlight in `#5EEAD4` with a soft cyan background wash (`rgba(94, 234, 212, 0.08)`).
- **Active Matrix Kernel Focus:** Wrapped in a 1px border of `#5EEAD4` with fine coordinate grid tick marks at the outer corners.

### Chips & Parameter Tags
- **Micro Tags:** Capsule pills with `label-caps` typography, 4px vertical / 10px horizontal padding, finished with `rgba(168, 85, 247, 0.12)` backgrounds and `#A8A1BA` text.
- **Status Indicators:** Feature a 6px pulsating dot with a tertiary cyan glow for GPU active execution status.

### Inputs & Sliders
- **Numeric Matrix Inputs:** Centered monospaced values, zero border by default, shifting to a vibrant 1px `#A855F7` stroke when focused.
- **Parameter Sliders:** Minimal 3px track in `rgba(168, 85, 247, 0.2)` with a filled gradient bar (`#EC38BC` to `#A855F7`) and a glowing circular thumb handle.

### Cards & Image Viewport Containers
- **Comparison Viewport:** Dual-pane visualizer separated by an interactive, glowing vertical divider beam (`#EC38BC` transitioning to `#5EEAD4`).
- **Floating Tool Panes:** `#14101F` frosted glass surfaces with subtle violet specular highlights along the top inner edge (`inset 0 1px 0 rgba(247, 245, 255, 0.1)`).
